## 🛠 Installation Guide

1. Navigate to the **backend** folder:
   ```bash
   cd backend
2. Install dependencies: npm install
3. Open the config/db.js file and replace the connection string with your MongoDB URL.
4. Start Backend Server: npm start

Now for frontend
1.  Goto todo-frontend
2.  npm install
3.  Enjoy!

🎉 Enjoy!
Now open the app in your browser and start managing your tasks efficiently! 🚀
